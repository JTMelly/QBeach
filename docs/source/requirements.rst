============
Requirements
============

Requirements
------------

* QGIS 3+
* XBeach 1.24.6057 "Halloween"

*QBeach* development began in the *QGIS 3* era. Meanwhile, *QGIS* has evolved, with new versions and major changes under the hood. Ideally, *QBeach* should work on *QGIS* versions 3 and later. This may change in the future as *QGIS 3* becomes less common in the wild.

In order to use the plugin, only *QGIS* is required. The model files it exports are designed to run with the "Halloween" version of *XBeach*. Model design and setup happens within *QGIS*, while running the actual model happens outside *QGIS*, using the software provided by *Deltares*.

*QGIS* works on most operating systems/desktop environments. The same goes for *QBeach*, beacuse it lives inside of *QGIS*. The simplest way to run *XBeach* is probably to get the precompiled builds from *Deltares*, though it is possible to compile from source on *Linux* machines and high-performance clusters.

Get the software
----------------

* `QGIS download <https://www.qgis.org/download/>`_
* `XBeach download <https://oss.deltares.nl/web/xbeach/release-and-source>`_
